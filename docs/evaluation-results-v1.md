# AIedu v1 正式评测结果

本页汇总 commit `7d6725801067e4db4c7e7bef1dafb2dd312394f6` 上的正式结果。数据集版本为 `v1`，回答模型为 `deepseek-v3.2`，Embedding 为 `text-embedding-3-large`。逐样本原始输出与生成报告保存在 `Aiedu-student-study FastAPI后端/evals/baselines/v1`，所有数字均可从 JSON 重新计算。

## RAG 消融

| 模式 | Recall@5 | MRR@10 | nDCG@5 | Hit@1 | p95 延迟 |
|---|---:|---:|---:|---:|---:|
| BM25 | 0.7188 | 0.5311 | 0.5395 | 0.3438 | 317.6 ms |
| Dense | 0.7969 | 0.7135 | 0.6938 | 0.5938 | 1520.3 ms |
| Hybrid RRF | 0.9219 | 0.7358 | 0.7550 | 0.6250 | 1773.6 ms |
| Hybrid RRF + Rerank | 0.9375 | 0.7286 | 0.7640 | 0.5938 | 7506.5 ms |

Rerank 相比 RRF 的 nDCG@5 仅增加 0.0090，95% bootstrap CI 为 `[-0.0910, 0.1098]`；Recall@5 增加 0.0156，但 warm p95 增量为 5893.9 ms。由于没有达到“nDCG@5 至少提升 0.03、增量 p95 不超过 500 ms”的预设门槛，当前推荐生产默认使用 Hybrid RRF，把 CPU reranker 保留为可选实验能力。

12 组端到端回答由模型盲评全部判为平局。项目内再次逐组抽查后，8 条可回答样本的回答均由引用支持，4 条不可回答样本均正确拒答，未观察到 rerank 的回答质量优势。该抽查属于 Codex 辅助的项目内审核，不等同于独立教师或第二标注员评审。

本轮 30 条答案的 Raw 输出没有结构、越界或证据定位错误，因此确定性校验没有改分，Reflection 触发率为 0。项目不能据此宣称 Reflection 带来提升；当前取舍是保留“仅在校验失败时最多触发一次”的安全机制，不默认增加第二次模型调用。

人工复核识别的 F1 为 0：模型没有标出数据集中预设的 3 份边界样本。这是当前批阅链路的真实短板，后续应单独改进低置信/题意歧义识别，而不是由 Reflection 指标掩盖。

## 结构化意图路由

| 模式 | Accuracy | Macro-F1 | 委派 Recall | 委派 F1 | 工具 Exact Match |
|---|---:|---:|---:|---:|---:|
| 关键词规则 | 0.6750 | 0.6043 | 0.6429 | 0.7826 | 0.7000 |
| Structured Outputs | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 0.9000 |

Structured Output 校验失败率和 fallback 率均为 0，10 条重复样本的一致率为 1.0；模型路由 p50/p95 分别为 3103.0/4107.9 ms。4 个工具组合失败均发生在个性化问题上：意图与学习助手委派正确，但模型和标注对“是否还需额外检索课程资料”判断不同。因此可以宣称路由和委派提升，不能宣称工具选择完全正确。

## 可用于简历的保守表述

> 构建 40 条人工复核的课程 RAG 评测集，对比 BM25、Dense、RRF 与 Cross-Encoder Rerank；Hybrid RRF 相比 Dense 将 Recall@5 从 79.69% 提升至 92.19%、nDCG@5 从 0.6938 提升至 0.7550。进一步 Rerank 仅带来 0.0090 nDCG@5 增益且 CPU warm p95 增加 5.89 秒，因此依据预设门槛保留为可选能力。

> 在 40 条意图样本上，Structured Outputs 路由相较关键词规则将 Macro-F1 从 0.6043 提升至 1.0000，学习助手委派召回率从 64.29% 提升至 100%，工具组合 Exact Match 达到 90%。

批阅结果目前适合表述为“建立 30 条答案的可复现消融基准，并通过实验发现当前 Reflection 未产生额外收益”，不建议包装成优化提升。

## 限制

- v1 数据由项目内 Codex 辅助审核，尚未经过独立教师双标或一致性统计。
- 样本来自同一门 C 语言课程，结论不能直接外推到其他课程。
- RAG reranker 实际运行在 CPU；本轮没有测量 GPU 延迟。
- Qdrant 客户端 1.15.1 对服务端 1.19.1 给出兼容性警告，查询成功但后续应统一版本后再做跨版本性能对比。
