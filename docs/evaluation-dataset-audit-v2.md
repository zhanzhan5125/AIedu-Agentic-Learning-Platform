# AIedu RAG v2 评测集审核记录

审核范围：`evals/v2/rag.json` 的 40 条问题与 43 个相关证据引用。审核方式为项目所有者授权 Codex 进行项目内逐条复核，并使用 offering 2 当前数据库切片验证内容哈希。该审核不等同于课程教师或第二位独立标注员复核。

## 审核结果

- 40 条问题沿用 v1：exact、semantic、chapter、multi_evidence、unanswerable 各 8 条。
- 32 条可回答问题的 43 个 `resource_title + content_hash` 均能解析到当前有效课程资料。
- 8 条不可回答问题保持空金标准，其中 4 条进入端到端拒答测试。
- 重新切片后的引用先通过规范化 5-gram 重叠自动映射；最终一轮跨页重叠迁移的最低映射分数为 0.9501。
- 章节概览问题改用从真实子标题生成的 `section_index`，不再引用 PDF 目录页或水印块。
- `rag-004`、`rag-010`、`rag-028` 保留多个必要/可接受证据，因此 v2 相关证据总数多于 v1。
- 数据集不包含学生姓名、学号、联系方式、真实学生答案或 API Key。

## 已知限制

- 多个相邻块可能都能支持同一答案，目前并未穷举所有替代相关块，仍可能存在评测假阴性。
- v2 同时改变了切片粒度、元数据和相关证据数量，v1/v2 整体指标不是严格单变量 A/B。
- 样本只来自一门 C 语言课程，对外发布前建议由教师抽查问题与证据，并报告标注者间一致性。
